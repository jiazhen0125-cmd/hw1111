# 臺中驛鐵道文化園區專題網頁

本專案為逢甲大學行銷學系專題介紹網頁，聚焦「國定古蹟臺中舊車站」與「舊軌道文化廊道」，透過「鐵道綠洲與古蹟新生」的核心定位，探討百年鐵道建築與舊山線記憶的當代流變，翻轉大眾對歷史古蹟過往呆板的刻板印象。

## 專案功能特色
- **SEO 最佳化**：包含完整的 Meta 標籤、Open Graph 社交協議與語意化 HTML5 標記（header, nav, aside, main, article, section, footer）。
- **RWD 響應式佈局**：支援手機、平板與桌上型電腦，影片與地圖採 16:9 自適應縮放與響應網格。
- **CSS Grid 系統**：實作復古鐵道深褐暖色調（`#5c4033`）與溫潤背景紙張色（`#fcfbfa`）之雙欄側邊導覽與卡片網格。
- **檔案模組化切割**：CSS 樣式表獨立抽離至 `css/hw07.css`，圖片資源統籌於 `images/` 資料夾。
- **導覽列與側邊欄架構**：整合頂部導覽列與固定式側邊欄目錄，實現流暢的單頁錨點切換與導覽體驗。
